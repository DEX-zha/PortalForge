# Experiments

Machine-readable experiment records are written by `ssa-archive experiment m1|m2` to `.local/dolphin-evidence/experiments/<id>.json` (schema `specs/001-ssa-level-research/contracts/experiment-record.schema.json`). They reference local game data and are not committed; this folder holds human-readable summaries and the reproduction procedure.

## Reproducing any experiment from its record

1. **Identity**: `inputs.game` must be the SSA dump `SSPP52` PAL revision 1 (`ssa-archive identify --game <wbfs>`).
2. **Original archive**: `inputs.archive_disc_path` with `inputs.original_sha256`; extract it with `ssa-archive disc-extract` and compare the hash.
3. **Workspace and rebuild**: `ssa-archive extract` then `ssa-archive rebuild` with the record's variant (`identical`, `sequential`, `reencode`) or, for M2, the `inputs.mutation` (`entry_index`, `offset`, `type`, `old_hex`, `new_hex`); the result must hash to `inputs.rebuilt_sha256`.
4. **Patch**: `inputs.patch_dir` and `inputs.descriptor` are regenerated by `ssa-archive patch --force`; descriptor paths use forward slashes.
5. **Runs**: replay `inputs.input_script` through `ssa-archive experiment m1|m2`; compare the `monitor_lines` (file-monitor sizes served for the patched path), the screenshots and `observed_effect` with the record. A run is only PASS with `crash_or_load_error: false` and, for M2, the predicted effect observed in every repeat.

## Entering the tutorial level (recorded 2026-09-12)

Script `tools/ssa-archive/src/experiments/input-scripts/level-027-entry.json`, recorded with `ssa-archive experiment explore` on the plain dump with Sonic Boom loaded at the title screen: wrist-strap screen → `A` → Activision logo → `A` → sky → `A` → title "Press A to begin" → figure load → `A` → autosave notice → `A` → Choose Play (Skyland Adventures) → `A` → Pick Game Slot (Save Game 1, 0 %) → `A` Continue Game → intro cinematic (balloon, Hugo) → `level/Level_027_Tutorial.arc` is read → Hugo dialogues advanced with `A` → "This Skylander is visiting from another adventure" prompt (`A` = No) → Sonic Boom stands next to Hugo; the Nunchuk stick moves the character. `Plus` opens the pause menu and is never used. Waits are wall-clock, tolerant to frame stalls during the 69 MB `Title.arc` load.

## Live memory probes (M2 candidate filtering)

`ssa-archive experiment live-probe --pattern <hex>... --poke match:<i>:<offset>=<value>[=<wait>] [--save-slot n]` boots the plain dump, enters the tutorial, searches MEM1/MEM2 for byte patterns copied from a decoded IGZ, writes a float at a found address and keeps before/after screenshots. Run `live-probe1` (2026-09-12) found the section-1 bytes of `level.bld` resident in MEM1 at `file offset + 0x80DBC020` and saved a native state in slot 6 at the tutorial start, which future probes can restore instead of replaying the 4.6 min entry script (state files live in `.local/dolphin-user/StateSaves/`, same game only, original level data).

## Runtime pointer scans (M3 convergence, 2026-09-13)

`ssa-archive experiment ptr-scan --file <decoded level.bld> --address <file offset>[,...] [--pattern <hex>] [--dimensions] --figure <.sky>` boots the plain dump, loads the figure, restores state slot 6 (tutorial start), snapshots MEM1 (and MEM2), reads back the resident bytes of each target object and diffs them against the file, then searches the snapshot for pointers to each target. `--dimensions` also dumps the whole resident object section to `.local/dolphin-evidence/<label>-section1.bin`; `igz fixups <decoded> <dump>` turns that dump into the complete fixup map (which words are pointers, ids, strings, class pointers; which objects the loader visited). One boot each, no archive mutation.

The spawn `tfbPhysicsModel` gains back-pointers to its type-92 owner (+0x6C, +0x118), heap links (+0x108, +0x134) and its position copied to +0xAC.
